# Créditos e licenças dos assets

Todo asset de terceiros usado no projeto precisa estar listado aqui **antes** de entrar no repositório.
Assets de teste ficam em `unity-app/Assets/_Project/Models/TestAssets/` para facilitar a troca futura.

Regras:
- Prefira **CC0** (Quaternius, KayKit, Kenney). Com **CC-BY**, credite o autor aqui e na tela de créditos do app.
- Evite **CC-BY-NC** e licenças "editorial use", porque elas impedem qualquer uso comercial no futuro.
- Mixamo: pode usar em projetos, mas não pode redistribuir os arquivos crus.
